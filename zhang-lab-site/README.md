# Zhang Lab GitHub Pages Template

This is a ready-to-deploy static website for the Zhang Lab.

## How to publish on GitHub Pages

1. Create a new GitHub repository named `yourusername.github.io` or any repository you want to publish.
2. Upload all files from this folder to the repository.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save. GitHub will publish the site.

## Files included

- `index.html` — homepage
- `research.html` — research overview
- `people.html` — lab members
- `publications.html` — publications list
- `resources.html` — datasets and tools
- `news.html` — lab news
- `join.html` — recruitment page
- `contact.html` — contact page
- `styles.css` — site styling
- `script.js` — mobile menu behavior
